# Theodia Playlists: Sermons

This repository distributes sermon audio playlists for the Theodia app. Each playlist package is a remote-MP3 audio playlist that streams or caches freely available sermon recordings.

## Packages

| Package | Source | Description |
| ------- | ------ | ----------- |
| `Charles-Finney-Revival-Sermons.playlist.zip` | [charlesgfinney.com](https://www.charlesgfinney.com/mp3finneyindex.htm) | Top 20 recordings from Charles G. Finney: two sermons from *Sermons on Important Subjects* plus the first eighteen *Lectures on Revival of Religion*. |
| `RA-Torrey-Revival-Addresses.playlist.zip` | Internet Archive / LibriVox | Complete public-domain recording of R. A. Torrey's revival addresses: an introduction plus seventeen evangelistic messages. |
| `Martyn-Lloyd-Jones-Sermon-Sampler.playlist.zip` | [MLJ Trust](https://www.mljtrust.org/sermons/) | Top 20 expository sermon selections from Dr. Martyn Lloyd-Jones at Westminster Chapel. |

## Usage

Install these packages in Theodia from **Settings → Resources**. The app will stream or cache the remote MP3 files as configured.

## License notes

- **Charles Finney** and **R. A. Torrey** recordings are public domain or freely shared by their hosts.
- **Martyn Lloyd-Jones** recordings are free to stream/download from MLJ Trust; verify redistribution terms on their site.

Always check the current source license and URL before redistributing.
